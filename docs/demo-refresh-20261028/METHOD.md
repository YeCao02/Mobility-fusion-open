# Frozen-v8 public replay: sample and display scope

The refresh uses completed accepted trajectory data. It selects2,000 distinct dataset identities per mainland GBA city and2,000 Shanghai residence identities. GBA covers the delivered2024-12-24 and2024-12-29; Shanghai covers available context within2026-05-01–14. Different periods/namespaces are not linked natural persons or population denominators.

Selection is a deterministic candidate convenience sample, not a population probability draw. GBA assignment uses the earliest available DAY_START representative H3 and the existing city mapping, not residence or dominant-city inference. One GBA source identity is assigned to at most one selected city. The same fixed public identity is retained across available dates.

Source UUIDs and private linkage/keys are withheld. Public IDs are fresh pseudonyms. POI names are withheld; visible coordinates and times retain the existing demonstration precision, so pseudonyms are not an anonymity guarantee. The execution program and detailed local provenance are retained privately and are not part of this public summary.

The independent local audit checked all selected identity/date raw, node and segment counts and endpoint relationships. The public receipt exposes only sample counts, validation flags and hashes of public manifests. GBA includes87 raw-only slots and5,846 empty date slots; Shanghai includes4,508 empty date slots. Empty slots are not fabricated observations or silently dropped dates.

The browser JSON is a reduced visual projection, not the lossless scientific archive. Primary-H3/time-envelope K/S matching and explicit input flags are display proxies, not complete internal engine judgments. Unavailable audit fields remain null. Per-node administrative city is separate from sample-cohort city; cells outside the existing mapping and crossings with an unknown endpoint remain unknown/null.

Only the current city/date200-ID page is requested as one processed/raw gzip pair. The OpenStreetMap basemap uses its standard no-key endpoint with visible attribution and ordinary browser cache, without bulk prefetch. Dataset validation, local software tests, interactive UI checks and live HTTPS readback are separate evidence levels.
