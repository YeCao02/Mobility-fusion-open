轨迹生成算法

本轮统一事件时间与空间表达，处理区间、间隙、重叠与节点关系，输出可关联的七类表。将分析日归属与跨日所需上下文区分，按完整标识处理其可用日期上下文，避免机械拆日丢失边界；不表示每人每天均有观测。逐字段、关系和往返还原检查用于保持工程优化前后的结果一致。

格式合法不等于真实个人活动。上海单个异常标识按用户决定排除，不再调查或补算；384,587条记录保留原始证据，已验收成果不改写。上海展开日输入6,889,068,945条=接收6,888,684,358条+最终排除384,587条。flow接收3,503,432个标识，residence接收4,736,801个；两批人数不相加当作全局去重人数。
